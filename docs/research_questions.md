# Research Questions

## Boundary and Usefulness

1. How much task usefulness is lost when raw personal data must remain local?
2. Which tasks benefit most from private compute after minimization?
3. When does a refusal or block increase user trust enough to justify lower task completion?

## Consent and Control

1. Which consent prompts produce real understanding instead of habituated approval?
2. Should consent attach to data items, purposes, layers, actions, or time windows?
3. How should revocation affect previous private-cloud or federated contributions?

## Privacy and Collective Intelligence

1. Which aggregate representations are useful without becoming reconstructable?
2. How should privacy budgets be represented to non-expert users?
3. Can local-first personal agents contribute to shared intelligence without recreating centralized surveillance?

## Agent Autonomy

1. What is the right autonomy ladder for personal AI: advise, draft, act-with-consent, or act-with-standing-delegation?
2. Which domains should never support standing delegation?
3. How should benchmarks penalize agents that complete tasks by violating user leverage or consent?

## Evaluation Methodology

1. Can personal-agent evals combine deterministic policy checks with human usefulness ratings?
2. What adversarial tests best predict real-world overreach?
3. What would a public leaderboard measure without encouraging unsafe optimization?
4. How should benchmark cards disclose synthetic scenarios, scoring assumptions, and residual risk?
