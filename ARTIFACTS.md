# PAISL Artifact Index

Complete index of generated artifacts, schema contracts, and fixtures. Most
files under `outputs/` are produced by `pnpm eval`; the env-dependent Docker
and OS-sandbox probes are produced by their dedicated commands (see README).
Start with [outputs/sample_eval_report.md](outputs/sample_eval_report.md),
[outputs/system_card.md](outputs/system_card.md), and
[docs/claim_evidence_index.md](docs/claim_evidence_index.md).

Version note: the public release candidate is `1.0.0-rc.0`. Some generated
filenames and component report identifiers retain `v0.18` / `0.18.0` as
historical evidence-lineage markers, not separate public release claims.
