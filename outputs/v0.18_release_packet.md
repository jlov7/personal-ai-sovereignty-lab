# Personal AI Sovereignty Lab (PAISL) 1.0.0-rc.0 Release Packet

## Release Position

This is a public benchmark-scaffold release candidate, not a validated benchmark standard. PAISL 1.0.0-rc.0 carries forward the v0.18 evidence lineage and hardens scoring and evidence: it adds a submitted-artifact runner that executes fixture agent artifacts, binds source digests and emitted traces to keyed-integrity receipts (HMAC under a public fixture key, integrity not authenticity), preserves broker and sandboxed execution attestations, and records Docker hardened-profile probes when Docker is available. Reviewers can inspect the supporting evidence directly: runnable code, schemas, generated logs, negative controls, adversarial prompt variants, deterministic adversarial execution, a reproducible multi-model adversarial sweep (gemma4:26b, qwen3:4b, llama3.2:3b), statistical reporting, egress enforcement probes, storage-backed runtime enforcement probes, keyed-integrity consent probes, key-custody lifecycle probes, brokered trace attestations, sandboxed execution attestations, submitted-artifact receipts, process-level egress guard probes, OS/container confinement evidence, executable tool-call traces, aggregate reconstruction-risk stress tests, aggregate attack stress tests, synthetic cohort uniqueness attacks, executable aggregate attacks, aggregate privacy challenges, external trace evaluation, construct-validity checks, artifact hashing, runtime manifest, Hugging Face-ready packaging, a reproducible multi-model transcript sweep, annotation-agreement tooling, baseline-submission tooling, an external-validation gate, and an annotation protocol. These artifacts support review of a local scaffold; they do not establish external validity until independent annotations and stronger model/agent baselines exist.

Version note: checked-in generated component reports that still carry `0.18.0` identifiers are preserving the historical evidence lineage. The public release candidate is `1.0.0-rc.0`.

## Bounded Public Claim

Supported:

> Personal AI Sovereignty Benchmark is a runnable open benchmark scaffold for evaluating user-sovereign personal agents across privacy, autonomy, consent, explainability, data minimization, and usefulness.

Not supported yet:

> This is a fully validated public benchmark standard or proof that any model is safe for personal-agent deployment.

## Open Blockers To A Credible, Externally Validated Benchmark

1. Three independent reviewers annotate at least five overlapping cases each.
2. All adversarial prompt variants are run against stronger live models and production-grade tool-agent implementations, not only deterministic calibration plans and bounded local sweeps.
3. At least one non-local-agent implementation is evaluated beyond in-process deterministic tool adapters.
4. A public issue/discussion process accepts external scenario criticism before a `v1.0` claim.
5. The scorecard is calibrated against independent human labels rather than only author-defined baselines.
6. Consent receipt signing uses production custody rather than deterministic fixture keys.
7. External systems run inside a production broker and hardened production sandbox rather than only deterministic local broker replay, guarded child-process execution, and fixture submitted-artifact execution.
